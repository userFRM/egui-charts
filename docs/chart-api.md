# Chart host contracts

Call `Chart::show` each frame and drain `Chart::drain_events` afterwards. A `ChartPointer` carries the rendered logical index, UTC time, UI position, pane, raw pane value, main bar, previous close, all added series with a matching timestamp (including hidden series), visible study values, hit target, modifiers and input device. Bars retain host JSON payloads. Missing timestamps have no added-series entry; main-series whitespace retains its slot. Price-based chart indices count displayed elements.

The host input integration can call `set_pointer_kind(Some(PointerKind::Pen))` before showing the chart. Keep it updated when the active device changes; `None` restores egui mouse/touch detection. egui itself cannot distinguish pens. Programmatic synchronized crosshairs do not emit local pointer moves. Click and double-click payloads use the same contract. The demo's API samples show a host legend and its hover tooltip using only the saved event, including formatted study values.

`set_price_formatter` supplies raw prices and `PriceFormatter::format_tick` supplies axis ticks. `set_percentage_formatter` receives percentage points or indexed values on relative scales, and percentage changes in readouts. `set_series_formatter(id, ...)` overrides a bar series' raw-price labels, readouts and ticks; a shared axis uses its first visible series. `set_volume_formatter` supplies volume readouts and configured volume studies, including studies added later. `None` restores the built-in formatting. Formatter implementations are shared `Arc`s and retained by PNG exports. CSV keeps numeric machine-readable values.

A legend shows the symbol's logo before its title, from `Legend::badge` or `Instrument::logo`, else the symbol's initial. `Legend::show_logo` hides the mark. After the title, a market status pill shows delayed or end-of-day data and, for a `Chart`, the session's state from its trading hours at the chart's clock (replay, server time, or the system clock). `Legend::show_market_status` and the chart's **Market status** setting hide the pill independently of the logo; host `LegendStatus` marks remain visible. Both settings default to shown, including in older saved layouts. Migration: `StatusLineOptions` literals add `show_market_status` or use `..Default::default()`.

Standalone legends built with `Legend::new` take `ValueFormatters` in their `formatters` field; its default preserves built-in formatting. `StudyValue::formatted_value` uses the chart-supplied formatted text when present, so host readouts match the chart. Direct `StudyValue` literals set `formatted: None` to use the declared units and precision.

`set_locale`, `set_date_format`, `set_time_formatter` and `set_session_provider` already support localized calendar names, crosshair/tooltip date patterns, separate time tick/hover methods and host session rules. Built-in price labels on price scales, their tags, the crosshair and the legend group thousands with `ChartConfig::thousands_sep` (`','` by default, `None` for plain digits); hosts supply decimal commas and currency conventions through their numeric formatters, whose labels are never grouped.

Read runtime options with `chart_options` and replace them with `set_chart_options`. `set_size` can constrain the widget's allocated size; `set_crosshair_position` takes UTC time and raw price. `export_png` returns encoded bytes from an isolated CPU-rendered frame. `ImageExportOptions::include_crosshair` controls the crosshair independently of host overlays. The demo saves these encoded bytes directly and includes the crosshair in its quick image export.

`hovered_series_on_top` applies within each pane to the main bars, added series, studies and custom series. Picking added series projects their own timestamps onto the main time axis and uses their price map. Rendering keeps legend rows in their original order.

Built-in main bars merge while zoomed out. Custom renderers override `Primitive::draw_merged`, receiving the physical-pixel merge factor; existing `draw` implementations remain unchanged. `view.point_groups(factor)` yields aligned source ranges covering the visible slots, including complete edge groups. Hosts choose how their own values and payloads aggregate. Cache expensive aggregates when `data_changed` runs and select the cached resolution during drawing. Lifecycle hooks run for widget frames, while exports reuse the attached renderer. Main-series merging retains OHLC extremes and the peak volume height; line merging retains first, low, high and last source values in source order.

Study menu chart actions are undoable and return their existing `ChartContextAction::Study { id, action }`. After `AddIndicator`, drain `take_indicator_source_request` to preselect `StudySource::Study { id, plot }` in the host chooser, then apply it with `set_indicator_source` to the created study. Alerts use `indicator_value_at` at the displayed index: for price-based charts this is the displayed element calculation, preserving the original study/output identity for the host alert service. `indicator_value_text` supplies the matching presentation.

`StudyScale::Shared(SeriesScale::Right)` and `Left` share with other members on that axis. `Separate(key)` creates or joins another labelled scale; the menu allocates an unused key for New scale and lists existing keys. `Overlay(key)` shares an unlabelled scale. Assignments are scoped to a pane. The primary scale in a non-main pane remains that pane's scale; other assignments fit their own group. `Main`, `Independent` and `None` retain their existing behavior. Overlay volume can be pinned through the same menu. Custom presentation implementations that accept shared placement retain the chart's `set_scale_mapping` update and expose it through `scale_mapping`; the chart's automatic `ConfiguredStudy` wrapper does this already.

`StudySettings::interval_range` evaluates every interval, in addition to the exact `hidden_intervals` exclusions. Time ranges compare nominal durations, including custom seconds; trade-based ranges compare thresholds within the same family. `Only` matches the exact interval. Old saved settings default to `All`. The global visibility toggle remains independent of these ranges.

`StudySettings::untagged_plots` lists the plots whose last value has no tag on the price scale; the legend still shows it. A study starts with the plots `Indicator::plot_tagged` leaves out, every plot of a study with more than four, and the study Style tab turns each plot's tag on and off. Settings saved before the field tag every plot. When an input changes the number of plots, the plots kept keep their choice and the plots added take the study's default. Migration: `StudySettings` literals add `untagged_plots: Vec::new()` to tag every plot; studies that should tag more than four plots by default override `Indicator::plot_tagged`.

Hosts own alert persistence, favorites storage, clipboard delivery and object-tree mounting. The demo routes these intents to its host services. `IndicatorDialog::open_for_chart(&chart, Some(source))` preselects the requested study output, lists compatible favorites first and preserves that source when adding the study, including in narrow windows.

Charts created directly or with a default `ChartBuilder` follow the active egui theme. Inherited chart colours update together with overlays; fields that differ from the previously inherited palette remain host overrides. `with_theme` or `set_theme_override(Some(...))` fixes one chart's palette. Clearing the override follows the context again and retains subsequent host edits. `set_theme` explicitly applies a palette to the chart and the egui context, and sibling charts follow on their next frame. Image exports retain the same palette rules.
Theme text roles also reach chart titles (`text.chart_title`), OHLC and study readouts (`text.ohlc`), secondary series, trading labels and chart controls. Pane legend rows measure their text height so larger text stays aligned with its controls.
