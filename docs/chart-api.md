# Chart host contracts

Call `Chart::show` each frame and drain `Chart::drain_events` afterwards. A `ChartPointer` carries the rendered logical index, UTC time, UI position, pane, raw pane value, main bar, previous close, all added series with a matching timestamp (including hidden series), visible study values, hit target, modifiers and input device. Bars retain host JSON payloads. Missing timestamps have no added-series entry; main-series whitespace retains its slot. Price-based chart indices count displayed elements.

The host input integration can call `set_pointer_kind(Some(PointerKind::Pen))` before showing the chart. Keep it updated when the active device changes; `None` restores egui mouse/touch detection. egui itself cannot distinguish pens. Programmatic synchronized crosshairs do not emit local pointer moves. Click and double-click payloads use the same contract. The demo's event-only legend and tooltip integration belongs to the demo lane.

`set_price_formatter` supplies raw prices and `PriceFormatter::format_tick` supplies axis ticks. `set_percentage_formatter` receives percentage points or indexed values on relative scales, and percentage changes in readouts. `set_series_formatter(id, ...)` overrides a bar series' raw-price labels, readouts and ticks; a shared axis uses its first visible series. `set_volume_formatter` supplies volume readouts and configured volume studies, including studies added later. `None` restores the built-in formatting. Formatter implementations are shared `Arc`s and retained by PNG exports. CSV keeps numeric machine-readable values.

Standalone legends take `ValueFormatters` in their `formatters` field; standalone `render_tooltip_with_options` takes it as the final argument. Its default preserves built-in formatting. `StudyValue::formatted_value` uses the chart-supplied formatted text when present, so host readouts match the chart. Direct `StudyValue` literals set `formatted: None` to use the declared units and precision.

`set_locale`, `set_date_format`, `set_time_formatter` and `set_session_provider` already support localized calendar names, crosshair/tooltip date patterns, separate time tick/hover methods and host session rules. Locale-derived number separators and shared currency formatting await #607 and #676. Hosts can supply those separators through their numeric formatter today.
