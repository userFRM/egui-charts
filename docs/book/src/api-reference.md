# API reference

[Open the Rust API reference →](api/egui_charts/index.html)

The reference is built from this revision with all crate features, matching the
feature selection used by docs.rs. It documents public types, method signatures,
configuration fields and module-level contracts.

| Module | Use it for |
| --- | --- |
| [`widget`](api/egui_charts/widget/index.html) | `Chart`, `ChartBuilder`, series and interaction |
| [`model`](api/egui_charts/model/index.html) | Bars, instruments, intervals, transforms and strategy results |
| [`data`](api/egui_charts/data/index.html) | Feeds, replies, sinks, trades, depth, recording and replay |
| [`studies`](api/egui_charts/studies/index.html) | Indicator contracts, built-ins and custom studies |
| [`drawings`](api/egui_charts/drawings/index.html) | Drawing models, interaction and persistence |
| [`scales`](api/egui_charts/scales/index.html) | Scale models, tick generation and formatters |
| [`config`](api/egui_charts/config/index.html) | Chart options and input configuration |
| [`theme`](api/egui_charts/theme/index.html) | Theme presets and egui styling |
| [`services`](api/egui_charts/services/index.html) | Host storage, search, signals, alerts and trading |
| [`ui`](api/egui_charts/ui/index.html) | Application components and their actions |

For the published 0.2.0 release, use [docs.rs](https://docs.rs/egui-charts/0.2.0).
For full applications using the public API, browse the
[examples](https://github.com/userFRM/egui-charts/tree/main/examples).
