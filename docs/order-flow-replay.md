# Recording and replaying order flow

The host supplies market data and owns files, network connections and playback scheduling. The library supplies a shared `data::ReplayClock`, binary recording streams and the same `Sink` used by live subscriptions. Existing bar replay remains available for sources that only supply candles.

Give every `ReplayEvent` a symbol, observation time and merge sequence. A symbol's time and sequence pair must be unique, including across trades, quotes and book messages. Equal instants across symbols share one clock and are ordered by sequence, then symbol. Payload times and symbols must agree with the envelope. Book snapshot and delta sequence numbers stay separate from the merge sequence and follow the live depth contract.

In the data adapter, write each observed event with `RecordingWriter::write` and push it with `ReplayEvent::push_to`. `RecordingWriter::new(BufWriter::new(File::create(path)?))` writes a native file; a `Vec<u8>` works in a browser. `finish` flushes and propagates storage errors. Periodically record a complete book snapshot with the sequence of the last applied book event. Per-order snapshots list each price's orders in queue order. The versioned binary format preserves raw fills, optional trade, aggressor and resting order ids, sale conditions and nanosecond timestamps. It uses fixed little-endian fields and length-prefixed records without external dependencies. `RecordingReader::read` returns events one at a time, reports malformed/truncated input and bounds each record to 16 MiB.

For playback, read the events, construct one `ReplayClock` for all symbols, and route each event it emits to that symbol's subscribed sink. A recording-backed `Datafeed` can answer `history` with an empty final page, resolve the instrument's tick size and retain each `Subscription::sink`. Pump playback outside egui context locks, before drawing charts. Call `advance` with real elapsed time between frames; `set_speed(2.0)` plays twice as fast and zero pauses. Advance includes events at the current clock time and delivers them once. Use `advance(Duration::ZERO)` to deliver the starting instant without moving time.

Before seeking, call `reset_replay(cutoff)` on every participating sink, then route the events from `clock.seek(cutoff)`. The reset clears prior chart bars, trades, quotes, books, depth columns, deduplication ids and partial trade bars on the next frame. The seek includes events at the cutoff. It rebuilds execution history from the start, including known executions before the depth anchor, and rebuilds depth from each symbol's latest snapshot at or before the cutoff. No future snapshot is used. Subsequent advances deliver only events after that position. Coordinate outstanding history replies in the host so they cannot reintroduce data from a previous playback position. Keep the recording feed subscribed while replaying; pausing the chart's feed unsubscribes its sink.

Trade, volume, delta and range bars use exactly the live aggregation rules. Volume and delta split a fill at an exact threshold while the raw tape retains it once. Unknown aggressor sides add volume and zero delta. Range bars require the instrument tick size and close at the first real execution that reaches the configured range. A jump across untraded prices can exceed the range; replay never invents trades there. A single fill producing more than 100,000 bars is rejected atomically. To reconstruct historical range bars directly, use `aggregate_trades_with_tick_size` with the same instrument tick size.

Feeds receiving both an execution event and its separate tape print must give both the same unique trade id. The raw store then counts the fill once. `Tick::aggressor_order_id` groups known fills into an aggressive order through `Chart::combined_trades`; `resting_order_id` identifies each resting order it filled. Per-price volume always uses the raw fills. `Chart::order_queue` exposes queue positions, largest orders and minimum-size filtered levels for host ladders and heatmaps. It returns no individual orders for aggregated-only sources.
