Enable [`ui`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/index.html) to compose application toolbars, panels, dialogs and reusable [`ui_kit`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui_kit/index.html)
controls around a chart. These are components for your layout. Keep them alive
between frames and handle the actions each component returns.

## Compose the workspace

The [`ui`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/index.html) module contains top and drawing toolbars, timeframe controls, side panels,
symbol and comparison dialogs, replay controls and trading components. The host
chooses their placement and applies their actions to the chart. Use
[host data services](../../../../host-data-services.md) for symbol catalogs and external analytics,
and [strategy reports](../../../../strategy-report.md) for host-produced backtest results.

The [terminal package](https://github.com/userFRM/egui-charts/tree/main/terminal)
assembles these components around a feed-backed chart and performs their actions. The repository's
[demo source](https://github.com/userFRM/egui-charts/tree/main/examples/demo)
shows a larger composition.

## Connect trading services

The [`services`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/index.html) module defines the host contracts for accounts and broker operations.
Implement [`Broker`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.Broker.html)
and attach it to [`Trading`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/trading/struct.Trading.html).
The UI offers broker selection, account views, order tickets, a depth ladder and
trading lines. A host broker supplies account state and receives confirmed orders.
Authentication, connections, execution and account persistence belong to your
application. Rendering trading controls does not create a brokerage connection.

Consult the [API reference](api-reference.mdx) for the service traits and each
component's action enum before wiring it into your application.
