## Panes

Panes share the chart's time axis and hold series or studies on their own price
scales. Overlays start in the price pane; oscillators can create separate panes.
Use [`Chart::add_pane`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.add_pane)
and [`move_series_to_pane`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.move_series_to_pane)
to place a series. Resize or reorder panes with [`set_pane_height`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_pane_height) and [`move_pane`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.move_pane);
[`PaneOptions`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.PaneOptions.html)
controls separator interaction. Start with [a built-in study](studies.mdx#attach-a-built-in-study).

## Markers

Attach trade signals or events to a bar series with
[`Chart::set_markers`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_markers).
[`Marker`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Marker.html)
sets the time, position, shape, colour and text; [`set_marker_options`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_marker_options) controls
autoscaling and drawing order. Markers belong to bar series, rather than study
outputs. For missing observations, use [whitespace bars](data-model.mdx#bars-and-series).
