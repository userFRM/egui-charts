A chart has one shared time axis and a price scale for each pane, with optional
independent scales for added series. Choose a task below to try it with fixed
synthetic data and the Rust source that runs the scene.

## Choose a price scale

The [price scale guide](price-scale.mdx) covers independent scales, normal,
logarithmic and relative modes, margins, inversion and manual ranges.

## Exchange time, not bar indices

The [time scale guide](time-scale.mdx) covers fitting, scrolling, visible ranges,
future whitespace and conversions between logical indices, UTC and screen points.
It also explains when the first frame's geometry becomes available.

## Strikes, maturities and other keys

The [horizontal scales guide](horizontal-scales.mdx) encodes numeric keys as bar
times and spaces actual samples proportionally without placeholder rows.

## Arrange panes

The [panes guide](panes.mdx) moves an added series below the main plot and
resizes it. Panes share a chart's time axis; a grid contains separate charts.

## Handle chart events

After [`Chart::show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.show),
drain [`Chart::drain_events`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.drain_events)
for pointer actions, crosshair movement and visible-range changes. Let the host
decide whether a click opens another view or changes application selection.
The [builder guide](../../../../builder-guide.md#synchronize-charts) shows how to
synchronize separate charts without feedback loops.
