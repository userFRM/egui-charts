The chart supplies time and price scales, pointer navigation and crosshair
interaction. [`ChartConfig`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/config/struct.ChartConfig.html) and [`ChartOptions`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/config/struct.ChartOptions.html) configure behaviour; the
[API reference](api-reference.mdx) documents their fields and defaults.

## Choose a price scale

[`PriceScaleMode`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/scales/enum.PriceScaleMode.html) selects
[normal](https://userfrm.github.io/egui-charts/docs/api/egui_charts/scales/enum.PriceScaleMode.html#variant.Normal),
[logarithmic](https://userfrm.github.io/egui-charts/docs/api/egui_charts/scales/enum.PriceScaleMode.html#variant.Logarithmic),
[percentage](https://userfrm.github.io/egui-charts/docs/api/egui_charts/scales/enum.PriceScaleMode.html#variant.Percentage) or
[indexed](https://userfrm.github.io/egui-charts/docs/api/egui_charts/scales/enum.PriceScaleMode.html#variant.IndexedTo100) pricing.
Use the instrument's precision and a price formatter for labels. A logarithmic
scale needs positive drawable prices. Relative scales need a usable reference;
when it is unavailable or zero, the renderer uses ordinary prices.

## Exchange time, not bar indices

Use [`Chart::visible_time_range`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.visible_time_range) and [`Chart::apply_synced_time_range`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.apply_synced_time_range) to share
UTC viewports. Use [`hover_time`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.hover_time) and [`set_synced_crosshair_time`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_synced_crosshair_time) for crosshairs.
Show each receiving chart once so its plot width is known. Select one source
chart and propagate only its changes to avoid feedback loops.

The [builder guide](../../../../builder-guide.md#synchronize-charts) includes the integration
snippet; the [synchronized charts example](https://github.com/userFRM/egui-charts/blob/main/examples/synchronized_charts.rs)
shows different intervals together. For deliberate future whitespace, use
[`set_visible_logical_range`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_visible_logical_range) with the chart's own logical coordinates.

## Handle chart events

After [`Chart::show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.show), drain [`Chart::drain_events`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.drain_events) for pointer actions, crosshair
movement and visible-range changes. Let the host decide whether a click opens
another view or changes application selection. Keep that decision outside the
renderer.
