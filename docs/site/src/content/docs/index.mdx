egui-charts is a financial charting engine for egui. Put an interactive chart in
your application, connect your data, and add analysis and workspace controls as
you need them. The same Rust code runs natively and in WebAssembly.

## Bring your own services

Your application owns market data connections, credentials, accounts and durable
storage. The library provides data contracts, chart rendering, study calculations
and host actions. It does not supply a market data feed or run trading strategies.

Start with [the data model](data-model.mdx), then use the
[builder guide](../../../../builder-guide.md) to connect events, persistence and
synchronized charts.
