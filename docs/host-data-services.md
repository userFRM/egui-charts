# Host data services

The host owns instrument catalogs, analytics, analyst estimates and market heatmap values. These APIs render and route that data without acquiring it or computing analytics.

## Try a report handoff

On the published guide, select **Run example** to render a `StrategyReport` delivered by a
synthetic host. Change **Fee per round trip**, then select **Deliver host report**. The
delivery counter changes once; ordinary chart frames do not execute the host's strategy.
The library computes metrics from the supplied trades and marked equity. The initial
two trades return +48 and -22 after fees, giving net profit 26, a 50% win rate and maximum
drawdown 22. An undefined annualized metric displays N/A.

<!-- example -->

`host_result` is the host's data boundary and `HostReport::show` is its small egui renderer.
No account, remote storage or market data service is included. A production host supplies
the actual result and decides when to deliver a replacement. The
[strategy report guide](strategy-report.md#try-a-host-produced-report) gives the hand
calculation and the complete report panel integration.

## Symbol search

Connect an [`Arc<dyn services::SymbolSearch>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.SymbolSearch.html) with [`SymbolSearchDialog::set_search_service`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_search_service) and [`CompareSymbolsDialog::set_search_service`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.CompareSymbolsDialog.html#method.set_search_service). Both dialogs keep accepting a local symbol list when no service is attached. The service returns promptly and answers through [`data::Reply<Vec<model::Instrument>>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.Reply.html); only the current text and filters can supply visible results.

Apply [`SymbolQuery::offset`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.offset) before [`limit`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.limit), preserving ordering between pages. A page shorter than the limit ends scrolling requests. The dialogs ask for another page when the last result comes into view. Instrument identifiers must match the identifiers accepted by the bar feed. [`Vec<Instrument>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html) implements the same search contract for a local catalog.

[`SymbolSearchDialog::set_storage`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_storage) connects recent selections through [`StoreKind::RecentSymbols`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.StoreKind.html#variant.RecentSymbols). Call [`show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.show) every frame, including while closed, so asynchronous storage can finish. Recent instruments retain their names and metadata, with the newest first. [`record_symbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.record_symbol) also records symbols opened elsewhere. Storage is read before a write; a failed read prevents replacement of the stored catalog. [`set_exchange_filter`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_exchange_filter) restricts service queries to a venue. An empty, unfiltered query shows recents; choosing a category, venue, country, sector or source browses the host catalog.

[`Instrument::logo`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.logo) and [`exchange_logo`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.exchange_logo) are image URIs loaded by egui's installed image loaders. The legend, symbol search, Compare, the order ticket, the account tables and trading notices draw the symbol's logo in a circle, and its first letter or digit on a neutral disc while it is unknown, loading or unreadable; the exchange mark falls back to the exchange name. Supply square logos of about 64 to 128 pixels, or SVG. The loaders decode raster images at full size and rasterize SVG at each drawn size. egui caches loaded textures and may evict unused SVG sizes; call [`egui::Context::forget_image`](https://docs.rs/egui/0.37.0/egui/struct.Context.html#method.forget_image) with the URI to invalidate a cached logo. On the web, `http` and `https` need egui_extras' `http` feature and a server that allows cross-origin requests; `file` is unavailable. `bytes` URIs registered with [`egui::Context::include_bytes`](https://docs.rs/egui/0.37.0/egui/struct.Context.html#method.include_bytes) work everywhere. [`Trading::set_instrument`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/trading/struct.Trading.html#method.set_instrument) supplies logos for account symbols the chart does not show; the chart instrument supplies its own symbol's logo. [`WatchlistPanel::set_mark`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/watchlist/struct.WatchlistPanel.html#method.set_mark) supplies watchlist logos with the same fallback. Exports use a fresh context without image loaders, so URI logos show the initial; pass a texture badge and its pixels in [`ImageExportOptions::textures`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.ImageExportOptions.html#structfield.textures) to include a logo. [`Instrument::country`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.country) labels compare rows. [`CompareSymbolsDialog::set_storage`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.CompareSymbolsDialog.html#method.set_storage) lists the recents symbol search keeps, and [`CompareAction::AddSymbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/enum.CompareAction.html#variant.AddSymbol) carries the [`ComparePlacement`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/enum.ComparePlacement.html) the user chose.

[`SymbolSearchDialog::set_sources`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_sources) fills the exchange menu, whose choice is the [`SymbolQuery::exchange`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.exchange) filter. [`set_countries`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_countries), [`set_sectors`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_sectors) and [`set_data_sources`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_data_sources) fill the country, sector and source menus, whose choices are [`SymbolQuery::country`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.country), [`sector`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.sector) and [`source`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.source); each menu also offers the values of a supplied symbol list. [`SymbolQuery::text`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.text) keeps a `VENUE:SYMBOL` query as typed, and [`SymbolQuery::qualified`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#method.qualified) reads its venue and symbol without replacing the exchange filter. Give the contracts of a futures root, or the listings of one security, the same [`Instrument::root`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.root): the dialog lists the first and expands the others under it, keeping the futures of each exchange apart, and returns the instrument chosen. Set [`Instrument::source`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.source) to tell providers of one listing apart, with distinct [`symbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.symbol) keys when the provider changes the feed request.

Text with an operator, such as `AAPL-MSFT`, is a [`services::SymbolExpression`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolExpression.html). The dialog searches the service for each of its symbols, lists the spread as a [`SymbolType::Spread`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/enum.SymbolType.html#variant.Spread) instrument once every symbol is found, and otherwise reports the fault. Chart a picked spread from the histories of its symbols with [`SymbolExpression::bars`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolExpression.html#method.bars).

## Signals

Connect [`Chart::set_signal_source(Some(source))`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_signal_source) to an [`Arc<dyn services::Signals>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.Signals.html). Each subscription starts empty. Push current signals first, then [`SignalEvent::Upsert`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Upsert), [`Remove`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Remove) and [`Clear`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Clear). Identities belong to the subscription; an upsert replaces its prior identity. Markers carry a time, optional price and direction. Levels carry a price and optional start time. Zones carry price bounds and time bounds.

The chart ends a subscription immediately on a symbol or interval change. Stop producing when [`Events::is_active`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.Events.html#method.is_active) becomes false. A burst over 10,000 pushes between frames ends the stream; the chart discards its state and subscribes again. Invalid prices or reversed zone bounds are discarded. No analytics run in the library.

The chart's Signals menu controls category visibility without deleting data. Hosts can also use [`set_signal_category_visible`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_signal_category_visible). Hover text comes from [`Signal::tooltip`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Signal.html#structfield.tooltip); clicks call [`Signals::clicked`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.Signals.html#method.clicked). Signal times are projected against the displayed history on every frame, including after history replacement and on price-based charts. A marker with a supplied price can appear in visible whitespace without a loaded bar.

## Analyst targets

Implement optional [`Datafeed::price_targets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.price_targets) to answer [`data::PriceTargets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.PriceTargets.html). Its default returns [`FeedError::NotSupported`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/enum.FeedError.html#variant.NotSupported), which shows neither targets nor an error. Prices must be finite, ordered `low <= average <= high`, and accompanied by an analyst count and publication and horizon dates. The horizon must follow publication.

The Symbol tab's **Analyst price targets** setting, or [`Chart::set_price_targets_visible`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_price_targets_visible), enables projections. They start at the last close with a value and end at midnight UTC on the horizon date. Leave enough future whitespace with [`set_visible_logical_range`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_visible_logical_range) to see that date and its labels. Automatic price fitting includes the target extremes while the projections reach the visible time range. The host price formatter receives instrument prices, including on percentage and indexed scales. Percentage change is `(target - close) / close * 100`; a zero close omits the percentage. Labels stay below the legend and quote controls in narrow charts. Hovering an endpoint or visible label shows the count and dates, including when the horizon is offscreen.

A symbol change clears the targets and ignores its old replies. [`reload_price_targets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.reload_price_targets) requests updated estimates; [`take_price_targets_error`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.take_price_targets_error) reports errors other than unsupported data. Hiding targets retains their answer. Price-based charts do not draw projections.

The demo's quick search has **Toggle API samples** for host signals and **Show analyst price targets** for SAMPLE's daily projection. Its synthetic feed implements these contracts on native and browser builds.

## Company financials

Implement optional `Datafeed::financials(symbol, reply)` to answer `data::CompanyFinancials` with the host's reported statements. Each `FinancialPage` names a page and its periods, oldest first; each `FinancialRow` supplies one optional figure per period. Keep missing figures as `None`; non-finite values render as unavailable. The currency labels amounts without converting them. The data types are available without UI features and remain re-exported from `ui::financials`.

The terminal requests figures for its active symbol and shows **Financials** in the symbol details' More menu only after a nonempty set of pages arrives. Pending requests, empty answers and the default `FeedError::NotSupported` leave the entry hidden. When a feed or instrument reports a service list, include `FeedService::Financials` to allow requests. Other errors appear once as terminal notices. Changing symbols discards the previous figures and ignores late replies.

Choosing Financials replaces the chart workspace with `FinancialsPanel` and closes the side panel to give the statements room. Open analysis follows symbol changes; **Back to chart** restores the chart. The panel provides statement tabs, a chart of the selected row and a table of all reported rows. A host composing its own UI can keep using `FinancialsPanel::new` with local figures, or call `request`, `poll` each frame and `is_available` to connect the optional feed method. The host owns financial data acquisition and refreshes; the library supplies no accounts or data provider.

## Market heatmap

[`ui::widget_bar::MarketHeatmapPanel`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapPanel.html) owns public lists of [`MarketHeatmapUniverse`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapUniverse.html) values (a named market with its [`MarketHeatmapEntry`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapEntry.html) instruments) and [`MarketHeatmapMetric`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapMetric.html) values (an identifier, label, unit, availability and optional colour saturation). Each entry supplies its symbol, group and the value of each metric by identifier; then call [`show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapPanel.html#method.show). It returns the selected symbol for the host to open. The user picks the universe, the metric that sizes the tiles and the metric that colours them independently, and a legend shows the size metric and the colour scale. [`MarketHeatmapPanel::selection`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapPanel.html#structfield.selection) holds the three choices: store it as [`UserSettings::market_heatmap`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.UserSettings.html#structfield.market_heatmap) and assign it back to restore them. A chosen metric or universe the host does not offer, or has no data for, stays chosen and shows as unavailable. Mutate the lists and request a repaint when host data changes; no new panel is needed.

Groups and their tiles share area in proportion to their weights. Invalid weights have no tile. Colours diverge from the theme background towards its rising/falling colours, saturating at the metric's [`saturation`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/panels/market_heatmap/struct.MarketHeatmapMetric.html#structfield.saturation) or at the largest magnitude shown; hover shows the original values. Group captions overlay the tiles so they do not change their proportional layout. Add [`RightBarIcon::MarketHeatmap`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/toolbar/enum.RightBarIcon.html#variant.MarketHeatmap) to the terminal rail when the host supplies this panel. The demo fills it with two universes of synthetic weights and updates the change and price metrics from its quotes.
