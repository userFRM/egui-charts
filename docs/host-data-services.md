# Host data services

The host owns instrument catalogs, analytics, analyst estimates and market heatmap values. These APIs render and route that data without acquiring it or computing analytics.

## Try a report handoff

On the published guide, select **Run example** to render a `StrategyReport` delivered by a
synthetic host. Change **Fee per round trip**, then select **Deliver host report**. The
delivery counter changes once; ordinary chart frames do not execute the host's strategy.
The library computes metrics from the supplied trades and marked equity. The initial
two trades return +48 and -22 after fees, giving net profit 26, a 50% win rate and maximum
drawdown 22. An undefined annualized metric displays N/A.

<!-- example -->

`host_result` is the host's data boundary and `HostReport::show` is its small egui renderer.
No account, remote storage or market data service is included. A production host supplies
the actual result and decides when to deliver a replacement. The
[strategy report guide](strategy-report.md#try-a-host-produced-report) gives the hand
calculation and the complete report panel integration.

## Symbol search

Connect an [`Arc<dyn services::SymbolSearch>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.SymbolSearch.html) with [`SymbolSearchDialog::set_search_service`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_search_service) and [`CompareSymbolsDialog::set_search_service`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.CompareSymbolsDialog.html#method.set_search_service). Both dialogs keep accepting a local symbol list when no service is attached. The service returns promptly and answers through [`data::Reply<Vec<model::Instrument>>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.Reply.html); only the current text and filters can supply visible results.

Apply [`SymbolQuery::offset`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.offset) before [`limit`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.limit), preserving ordering between pages. A page shorter than the limit ends scrolling requests, unless the service reports through [`SymbolSearch::leaves_results_out`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.SymbolSearch.html#method.leaves_results_out) that it leaves out results it cannot read: then an empty page ends them. Such a service answers [`FeedError::Other`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/enum.FeedError.html#variant.Other) with the first reason for a full page with no readable results. The dialogs automatically skip these pages at the next server offset, stopping after three consecutive such pages and showing the first reason. A readable page resets this count; network, HTTP and other request failures stop paging immediately. Each page starts the limit after the previous one. The dialogs ask for another page when the last result comes into view. The returned symbol keys must match those accepted by the bar feed. [`Vec<Instrument>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html) implements the same search contract for a local catalog.

[`SymbolSearchDialog::set_storage`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_storage) connects recent selections through [`StoreKind::RecentSymbols`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.StoreKind.html#variant.RecentSymbols). Call [`show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.show) every frame, including while closed, so asynchronous storage can finish. Recent instruments retain their names and metadata, with the newest first. [`record_symbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.record_symbol) also records symbols opened elsewhere. Storage is read before a write; a failed read prevents replacement of the stored catalog. [`set_exchange_filter`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_exchange_filter) restricts service queries to a venue. An empty, unfiltered query shows recents; choosing a category, venue, country, sector or source browses the host catalog.

[`Instrument::logo`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.logo) and [`exchange_logo`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.exchange_logo) are image URIs loaded by egui's installed image loaders. The legend, symbol search, Compare, the order ticket, the account tables and trading notices draw the symbol's logo in a circle, and its first letter or digit on a neutral disc while it is unknown, loading or unreadable; the exchange mark falls back to the exchange name. Supply square logos of about 64 to 128 pixels, or SVG. The loaders decode raster images at full size and rasterize SVG at each drawn size. egui caches loaded textures and may evict unused SVG sizes; call [`egui::Context::forget_image`](https://docs.rs/egui/0.37.0/egui/struct.Context.html#method.forget_image) with the URI to invalidate a cached logo. On the web, `http` and `https` need egui_extras' `http` feature and a server that allows cross-origin requests; `file` is unavailable. `bytes` URIs registered with [`egui::Context::include_bytes`](https://docs.rs/egui/0.37.0/egui/struct.Context.html#method.include_bytes) work everywhere. [`Trading::set_instrument`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/trading/struct.Trading.html#method.set_instrument) supplies logos for account symbols the chart does not show; the chart instrument supplies its own symbol's logo. [`WatchlistPanel::set_mark`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.WatchlistPanel.html#method.set_mark) supplies watchlist logos with the same fallback. The user hides them per list with the Symbol logos box of the list's More menu, saved as [`Watchlist::show_logos`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Watchlist.html#structfield.show_logos). Exports use a fresh context without image loaders, so URI logos show the initial; pass a texture badge and its pixels in [`ImageExportOptions::textures`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.ImageExportOptions.html#structfield.textures) to include a logo. [`Instrument::country`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.country) labels compare rows. [`CompareSymbolsDialog::set_storage`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.CompareSymbolsDialog.html#method.set_storage) lists the recents symbol search keeps, and [`CompareAction::AddSymbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/enum.CompareAction.html#variant.AddSymbol) carries the [`ComparePlacement`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/enum.ComparePlacement.html) the user chose.

[`SymbolSearchDialog::set_sources`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_sources) fills the exchange menu, whose choice is the [`SymbolQuery::exchange`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.exchange) filter. [`set_countries`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_countries), [`set_sectors`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_sectors) and [`set_data_sources`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/symbol_search/struct.SymbolSearchDialog.html#method.set_data_sources) fill the country, sector and source menus, whose choices are [`SymbolQuery::country`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.country), [`sector`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.sector) and [`source`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.source); each menu also offers the values of a supplied symbol list. [`SymbolQuery::text`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#structfield.text) keeps a `VENUE:SYMBOL` query as typed, and [`SymbolQuery::qualified`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolQuery.html#method.qualified) reads its venue and symbol without replacing the exchange filter. Give the contracts of a futures root, or the listings of one security, the same [`Instrument::root`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.root): the dialog lists the first and expands the others under it, keeping the futures of each exchange apart, and returns the instrument chosen. Set [`Instrument::source`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.source) to tell providers of one listing apart, with distinct [`symbol`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.symbol) keys when the provider changes the feed request. Give an instrument its ISIN, CUSIP or other codes with [`Instrument::with_identifier`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#method.with_identifier): a supplied symbol list finds it by any of them, typed exactly in any case and with or without spaces, and both dialogs show the identifier the query names after the description. A search service that matches identifiers returns them in [`Instrument::identifiers`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Instrument.html#structfield.identifiers) for the same display.

Text with an operator, such as `STOCKA-STOCKB`, is a [`services::SymbolExpression`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolExpression.html). The dialog searches the service for each of its symbols, lists the spread as a [`SymbolType::Spread`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/enum.SymbolType.html#variant.Spread) instrument once every symbol is found, and otherwise reports the fault. Chart a picked spread from the histories of its symbols with [`SymbolExpression::bars`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.SymbolExpression.html#method.bars).

## Signals

Connect [`Chart::set_signal_source(Some(source))`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_signal_source) to an [`Arc<dyn services::Signals>`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.Signals.html). Each subscription starts empty. Push current signals first, then [`SignalEvent::Upsert`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Upsert), [`Remove`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Remove) and [`Clear`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/enum.SignalEvent.html#variant.Clear). Identities belong to the subscription; an upsert replaces its prior identity. Markers carry a time, optional price and direction. Levels carry a price and optional start time. Zones carry price bounds and time bounds.

The chart ends a subscription immediately on a symbol or interval change. Stop producing when [`Events::is_active`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.Events.html#method.is_active) becomes false. A burst over 10,000 pushes between frames ends the stream; the chart discards its state and subscribes again. Invalid prices or reversed zone bounds are discarded. No analytics run in the library.

The chart's Signals menu controls category visibility without deleting data. Hosts can also use [`set_signal_category_visible`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_signal_category_visible). Hover text comes from [`Signal::tooltip`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/struct.Signal.html#structfield.tooltip); clicks call [`Signals::clicked`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/trait.Signals.html#method.clicked). Signal times are projected against the displayed history on every frame, including after history replacement and on price-based charts. A marker with a supplied price can appear in visible whitespace without a loaded bar.

## Analyst targets

Implement optional [`Datafeed::price_targets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.price_targets) to answer [`data::PriceTargets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.PriceTargets.html). Its default returns [`FeedError::NotSupported`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/enum.FeedError.html#variant.NotSupported), which shows neither targets nor an error. Answer in the instrument's own currency and unit. While the host has chosen a conversion with [`Chart::set_conversion`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_conversion), the chart asks [`Datafeed::price_targets_converted`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.price_targets_converted) instead, for targets in that currency or unit. Its default also returns `NotSupported`, so a feed that cannot convert them shows none rather than targets in another currency. Prices must be finite, ordered `low <= average <= high`, and accompanied by an analyst count and publication and horizon dates. The horizon must follow publication.

The Symbol tab's **Analyst price targets** setting, the **Analyst price forecast** study ([`AnalystPriceForecast`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/studies/struct.AnalystPriceForecast.html), in the Price category and also found as Analyst price targets or Price Target), or [`Chart::set_price_targets_visible`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_price_targets_visible) enables projections. The setting and the study stay in step: turning the setting on adds the study, adding the study turns the setting on, and removing the last such study, for example with its legend row, turns it off. The chart draws the targets while the study is shown in the main series' pane, so hiding the study, or every study, hides them. Layouts saved before the study existed restore with it when they hold the setting. A host that passes its feed's capabilities to [`SettingsDialog::set_feed_capabilities`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/dialogs/chart_settings/struct.SettingsDialog.html#method.set_feed_capabilities) offers the setting only when they declare [`FeedService::PriceTargets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/model/enum.FeedService.html#variant.PriceTargets) for the symbol. Dotted projections start at the close of the last bar with a value that opens by the end of the publication date in UTC, or of the first bar with a value when the history starts later, and end at midnight UTC on the horizon date. Targets above that close use the positive colour and those below it use the negative colour for their lines, labels and the area between the projections on each side of that close. The fill uses the colour's opacity; lines and labels stay opaque. The Symbol tab's **Positive** and **Negative** settings, or [`ChartConfig::price_target_positive_color`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/config/struct.ChartConfig.html#structfield.price_target_positive_color) and [`price_target_negative_color`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/config/struct.ChartConfig.html#structfield.price_target_negative_color), choose the colours. The study's **Positive** and **Negative** outputs edit the same colours, and hiding an output hides the targets on that side. The default `Color32::PLACEHOLDER` follows the theme's up and down candle colours, with the fill at 20% opacity. A fully transparent choice omits the fill and uses the theme colour for lines and labels. Leave enough future whitespace with [`set_visible_logical_range`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_visible_logical_range) to see that date and its labels. Automatic price fitting includes the drawn targets while the projections reach the visible time range. The host price formatter receives instrument prices, including on percentage and indexed scales. Percentage change is `(target - close) / close * 100` from the last close with a value; a zero close omits the percentage. Labels stay below the legend and quote controls in narrow charts. Hovering an endpoint or visible label shows the count and dates, including when the horizon is offscreen.

A symbol change, a changed conversion and entering or leaving a [market replay](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.set_market_replay) clear the targets and ignore their old replies. A market replay draws only the targets its driver answers, which are none, and leaving it asks the live feed again. A market or bar replay draws targets only once its time has passed their publication date in UTC. [`reload_price_targets`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.reload_price_targets) requests updated estimates; [`take_price_targets_error`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/widget/struct.Chart.html#method.take_price_targets_error) reports errors other than unsupported data. Hiding targets retains their answer. Price-based charts do not draw projections.

The demo's quick search has **Toggle all sample overlays** for host signals and **Analyst price targets** for SAMPLE's daily projection. On another symbol, on a price-based chart type or while the price series is hidden, it says why and leaves the chart unchanged. Its synthetic feed implements these contracts on native and browser builds.

## Company financials

Implement optional [`Datafeed::financials`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.financials) to answer [`data::CompanyFinancials`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.CompanyFinancials.html) with the host's reported statements. Each [`FinancialPage`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.FinancialPage.html) names a page and its periods, oldest first; each [`FinancialRow`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.FinancialRow.html) supplies one optional figure per period. Keep missing figures as `None`; non-finite values render as unavailable. The currency labels amounts without converting them. The types need no UI feature and are still re-exported from `ui::financials`.

[`SymbolDetailsPanel`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html) asks its feed for each new symbol's figures along with its details and holds a nonempty answer in [`financials`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.financials). It ignores answers for an earlier symbol or a replaced feed; the default [`FeedError::NotSupported`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/enum.FeedError.html#variant.NotSupported) shows nothing, and other errors show in the panel. The terminal offers **Financials** in the panel's More menu only once figures are held. Choosing it closes the side panel and shows [`FinancialsPanel`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/financials/struct.FinancialsPanel.html) in place of the charts, with statement tabs, a chart of the selected row and the table of all reported rows. It follows symbol changes, and **Back to chart** restores the charts. A host composing its own UI opens [`FinancialsPanel::new`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/financials/struct.FinancialsPanel.html#method.new) with the held figures when [`take_financials_request`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.take_financials_request) reports the choice. The host owns financial data acquisition and refreshes; the library supplies no accounts or data provider.

The panel also asks [`Datafeed::calendar`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.calendar) for the symbol's earnings and dividends of the next year, naming it in [`CalendarQuery::symbols`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/struct.CalendarQuery.html#structfield.symbols), and shows the next of each under Upcoming events; answer only that symbol's events, as the panel ignores events of another symbol. It asks [`Datafeed::news`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/data/trait.Datafeed.html#method.news) for the symbol's three newest stories, shown under News, and reports an opened headline through [`take_news_action`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.take_news_action): its link, or the chart at its time for a story without one. An empty or unsupported answer hides its section. The Technicals section rates the bars the host passes to [`set_bars`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.set_bars) each frame with the Technical Ratings study, and shows the summary, moving-average and oscillator ratings of the latest bar with values.

Offer the further sections the host can fill with [`set_detail_sections`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.set_detail_sections): analyst estimates, options figures, earnings calls, documents, fund holdings, credit ratings and bonds, each a [`DetailSection`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/enum.DetailSection.html). The panel asks for every offered section once per symbol through [`take_market_requests`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.take_market_requests) as [`MarketDetailRequest::Section`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/enum.MarketDetailRequest.html#variant.Section); answer with [`set_detail_rows`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.set_detail_rows) and [`DetailRow`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.DetailRow.html) values, each a label and a value with an optional note and link, in the host's own words. Answers for another symbol are ignored, an empty answer says there is no data, and [`MarketDetail::Unavailable`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/enum.MarketDetail.html#variant.Unavailable) hides the section for that symbol. A section that is not offered is neither drawn nor listed in the Layout menu. A click on a row with a link returns the row through [`take_opened_row`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.SymbolDetailsPanel.html#method.take_opened_row) for the host to open the document or recording, such as in a browser or its own player. The host owns this data and its sources; the library supplies none.

## Market heatmap

[`ui::widget_bar::MarketHeatmapPanel`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapPanel.html) owns public lists of [`MarketHeatmapUniverse`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapUniverse.html) values (a named market with its [`MarketHeatmapEntry`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapEntry.html) instruments) and [`MarketHeatmapMetric`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapMetric.html) values (an identifier, label, unit, availability and optional colour saturation). Each entry supplies its symbol, group and the value of each metric by identifier; then call [`show`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapPanel.html#method.show). It returns the selected symbol for the host to open. The user picks the universe, the metric that sizes the tiles and the metric that colours them independently, and a legend shows the size metric and the colour scale. [`MarketHeatmapPanel::selection`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapPanel.html#structfield.selection) holds the three choices: store it as [`UserSettings::market_heatmap`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/services/struct.UserSettings.html#structfield.market_heatmap) and assign it back to restore them. A chosen metric or universe the host does not offer, or has no data for, stays chosen and shows as unavailable. Mutate the lists and request a repaint when host data changes; no new panel is needed.

Groups and their tiles share area in proportion to their weights. Invalid weights have no tile. Colours diverge from the theme background towards its rising/falling colours, saturating at the metric's [`saturation`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/struct.MarketHeatmapMetric.html#structfield.saturation) or at the largest magnitude shown; hover shows the original values. Group captions overlay the tiles so they do not change their proportional layout. Add [`RightBarIcon::MarketHeatmap`](https://userfrm.github.io/egui-charts/docs/api/egui_charts/ui/widget_bar/enum.RightBarIcon.html#variant.MarketHeatmap) to the terminal rail when the host supplies this panel. The demo fills it with two universes of synthetic weights and updates the change and price metrics from its quotes.
