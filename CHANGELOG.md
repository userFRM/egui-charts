# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to Semantic Versioning.

## [Unreleased]

### Added

- Price-based chart settings offer `BoxSizeMethod::Fixed`, Wilder `Atr { period, multiplier }` and `Percentage` for Renko, Kagi, Point and Figure and Range. `Chart::set_chart_type_params` resolves the selected methods from loaded history, waiting for the ATR seed when needed, then freezes the sizes through streaming updates, corrections and feed prepends. Reapplying parameters or replacing the dataset with `set_data` recalculates them; changing the symbol or interval reloads history and recalculates too. Percentage uses the absolute latest close, with 1 meaning 1%. Renko, Kagi and Line Break accept `PriceBasedSource::Close` or `HighLow`; without intrabar ordering, a continuation takes priority when both thresholds are crossed. `renko_wicks` paints the brick's actual high and low; close input tracks close extremes and high/low input tracks bar extremes. The Symbol tab edits these parameters, which serialize with chart type settings. Migration: chart parameter literals add the method, source and wick fields or use defaults; `RenkoConfig`, `KagiConfig` and `LineBreakConfig` literals add `source` or use their constructors; `RenkoBrick` literals add `high` and `low`. `SeriesSettingsAction::Apply` carries its settings in a `Box`; callers constructing that action wrap settings with `Box::new`, and readers can borrow or dereference them. `RenkoConfig::from_atr` and `KagiConfig::from_atr` now use Wilder smoothing and require a complete seed instead of averaging the latest ranges. ([#633](https://github.com/userFRM/egui-charts/issues/633))

- `ChartTypeParams::styles` retains independent line, step line, marker, area and baseline colours, widths and line styles; Area has separate top and bottom fill stops, Baseline has separate line and fill colours on each side, and markers have a configurable radius. The series settings Symbol tab edits the current type. `Chart::series_settings` reads the current values for opening the dialog, and applying them leaves candle colours independent. Chart types, parameters and styles support serde for host-owned saved settings. Migration: `ChartTypeParams` literals add `styles` or use `..Default::default()`; `SeriesSettings` literals add `chart_type` and `chart_type_params`, or use the defaults. ([#562](https://github.com/userFRM/egui-charts/issues/562))

- `Chart::bar_clock` shares the resolved chart, exchange or system-local calendar with host rebuilds. `BarClock::with_timezone` and `with_local_timezone` align intraday and calendar windows, including repeated hours and short or long days. `HistoryRequest::clock` and `Subscription::clock` give hosts the same boundaries as the chart; changing the chart timezone reloads the series. `resample` and `aggregate_trades` accept either a timeframe for UTC or a supplied clock. Migration: inline parsed arguments to those functions specify `.parse::<Timeframe>()`; subscription destructuring includes `clock` or `..`.

- `Sink::advance_time` opens an empty current time bar on a trusted feed heartbeat, carrying the last close with zero volume until the first execution sets its OHLC. Count intervals wait for executions. `data::aggregate_trades` rebuilds chronological trade history with the same aggregation, validation and duplicate-id rules as the live sink.
- The native and web demos backfill to the current clock and stream deterministic synthetic trades and best bid/ask quotes through the public feed API. The default one-minute candle grows on every execution; the interval menu rebuilds second and count bars from a bounded trade buffer, with seven days of minute history built from the same executions for coarse views. Session filtering uses the instrument windows and the chart's extended-hours choice. A small pause/resume control freezes the feed. The footprint sample pauses streaming while it is inspected. Timed repaints follow executions and countdown seconds, with no worker thread.
- `Chart::set_feed_paused` suspends requests and unsubscribes while a host supplies replay bars. Resuming reloads the selected symbol and interval from the host feed. The demo retains replay when switching intervals and restores the preceding pause state when leaving replay.

- `Timeframe::Ticks(NonZeroU64)` and the interval menu offer 1, 10, 100 and 1000 execution bars. `Sink::push_tick` counts accepted trades across frames, retains exact OHLCV and keeps replayed ids from consuming a count. Replaying retained executions rebuilds the partial final bar when changing intervals. Count bar timestamps keep nanosecond precision, advancing by one nanosecond when opening times would collide. Migration: exhaustive `Timeframe` and `TimeframeUnit` matches need a tick arm. `duration_ms()` and `duration()` return zero for count intervals, which have no time duration; check the variant before stepping time. `Timeframe::all()` continues to list time intervals only.

- `MACombination` combines two to fourteen `AverageLine`s with independent simple, exponential, weighted, Wilder, volume-weighted or Hull formulas, lengths, sources and colours. `MACross`, `EMACross` and `MultipleMA` share its calculations with their existing defaults. The factory adds `SMA/EMA Cross`, `Triple MA` and `MA Ribbon`; the ribbon has twelve evenly spaced lengths, individual direction colours, a thicker slowest line and a fading purple bottom fill, with a muted variant available directly. Crossing markers identify changes of side, ignore touches and disappear when a live correction cancels the cross. ([#549](https://github.com/userFRM/egui-charts/issues/549))

- `LinearRegressionChannel` fits the trailing window with upper, middle and lower lines, residual deviation bands with an `n - 1` denominator, selectable price source, Pearson correlation label and optional right extension. Updates clear expired bars and refit the trailing window on every live change, independently of history length. Right extensions project prices before mapping to the axis, including logarithmic and inverted scales. Drawings share the same headless least-squares maths. ([#548](https://github.com/userFRM/egui-charts/issues/548))

- Charts pass instrument time zones and sessions to studies when added and when metadata arrives or changes, so a dialog-created VWAP follows the exchange session. Clearing metadata restores the study's configured time zone and session. VWAP supports quarter and year anchors, percentage bands, and `with_event_anchors` for earnings, dividend or split timestamps supplied by the host. Event anchors reset on the first bar at or after the timestamp, including after a market gap. ([#163](https://github.com/userFRM/egui-charts/issues/163))
- `data::Footprint`, `FootprintBar` and `FootprintLevel` aggregate chronological executions per UTC bar and integer price row, with separate bid, ask and unknown volume, intrabar delta extremes, POC, contiguous value area, horizontal and diagonal imbalances and inclusive trade-size filtering. Invalid, out-of-order or overflowing executions return an error without changing the aggregation; executions with unknown aggressor never contribute to delta.
- `studies::trade_delta` computes exact execution-based delta and cumulative delta candles, with host-defined session or period resets and independent rolling volume and delta totals. `chart::series::render_trade_delta` draws delta histograms or cumulative candles in a supplied pane. The existing bar-estimated `CVD` remains available separately.
- `chart::overlays::render_footprint` draws up to four bid/ask, volume, delta or delta/volume columns per bar, with profile or cell fills, volume, delta or imbalance colours, POC and value-area highlights, manual or automatic row grouping and cached text layouts hidden below the minimum row height. Both dominant diagonals retain their side colours, and sub-unit volumes stay nonzero in labels. `Chart::show_footprint` replaces the price series while keeping the legend, cursor and studies above it. The demo's Menu exposes a Footprint toggle using deterministic synthetic executions from its fixture; turning it off restores the previous time scale.
- `studies::footprint_studies` identifies stacked diagonal imbalance zones, unfinished auctions, naked POCs, delta POCs, volume clusters strictly above the configured volume share and small extreme prints using a host-supplied size threshold. Stacks and naked POCs extend until the first later traded range revisits them. `chart::overlays::render_footprint_studies` and `render_footprint_statistics` paint the annotations and per-bar volume, bid, ask, delta, delta extremes, cumulative delta, delta percentage and ask/bid ratio.
- `data::Sink::push_quote` coalesces best bid/ask quotes per frame and connects the latest matching quote to the chart legend. Invalid, mismatched or older quotes do not replace the current or pending quote; reloading the feed clears it.
- `Drawing::pitchfork` stores per-level colour, visibility and line style, with mirrored levels at 0, 0.5, 1 and 1.5 and filled bands by default. Hidden levels remove both adjacent bands. Old drawings use the defaults. Parallel channels support `channel_midline`, `fill_color`, `extend_left` and `extend_right`, with selection following the lines and filled area. Migration: `Drawing` struct literals set `pitchfork` and `channel_midline`, or use `Drawing::new`.

- `Session::with_extended_windows` and `with_holidays` describe host-owned trading hours and closures. `ExchangeSessionProvider` starts each trading date at its earliest regular or extended window, handles overnight sessions, and resolves repeated opens to their first instant and missing opens to the clock jump. `Chart::set_session_provider` accepts host break logic.
- Extended-hours bars are shaded independently of session dividers, including throughout a repeated hour after an overnight open. `ChartConfig::show_extended_hours` switches shading off, and `extended_hours_color` overrides the faint active-theme accent. Migration: chart configuration literals need these fields or `..Default::default()`.
- `Chart::set_extended_hours` chooses regular hours or regular and extended hours, reloading history and the stream together. `HistoryRequest::extended_hours` and `Subscription::extended_hours` carry that choice to the host feed, including older history pages. Migration: add `extended_hours` to request and subscription literals and destructuring, or use `..` when ignoring it in a pattern. Feeds must honor the field (`false` requests regular hours); hosts supplying bars directly replace their data after a choice.

- Chart settings now retain and apply title format, quote controls and independent study title/input/value visibility. `Chart::set_indicator_inputs` supplies study input captions, retained through host templates; status-line volume no longer hides the histogram. The settings dialog keeps one top edge across tabs through `Modal::top`.
- Price scale placement and independent current/previous close labels and lines now reach rendering on either axis. Countdown visibility is honoured, with its default enabled to retain the existing displayed countdown. Migration: add `..Default::default()` to `ChartConfig`, `settings_menu::data::StatusLineOptions`, `ScalesAndLinesSettings` and `IndicatorPaneConfig` literals, or set the new visibility fields explicitly. Construct `Legend` with `Legend::new` and set its public fields; it has no `Default` implementation. Previous close is the last bar before the latest trading date.

- `TopToolbar::indicator_templates` accepts host-owned saved study names and ids. Its anchored menu emits save/apply intents; the demo keeps cloned study sets in memory for the session. Migration: replace `TopToolbarAction::OpenIndicatorTemplates` matches with `SaveIndicatorTemplate` and `ApplyIndicatorTemplate(id)` handlers. Opening the popup emits no action.

- `Symbol::with_market` supplies an exchange and optional instrument kind for symbol search. Empty queries list the host catalog, with host-supplied recents first, category chips for available kinds and kind/exchange metadata in each row. Migration: `Symbol` struct literals need `exchange` and `symbol_type`, or use `Symbol::new`.

- `TabBar::pills` renders rounded tab chips through the shared tab component; the indicator browser uses them.

- `top_toolbar::buttons::toolbar_tooltip` attaches compact toolbar tips with optional platform shortcut chips. `Modal::rounding` and `Modal::fill` preserve per-dialog styling, and an empty modal title lets a search row serve as the header.

- `Chart::set_instrument`, `set_legend_badge`, `set_legend_statuses` and `set_quote` connect host metadata and current bid/ask to the responsive legend. Historical OHLC and study values follow the pointer independently of quotes, including over the axis add cell. `take_quote_action` retains buy/sell intents until taken; changing symbols clears supplied metadata and quotes. The demo labels generated data with SIM and records quote intents without submitting orders.
- `Chart::set_session_quote` and `set_events` connect independent session prices and event badges. `take_event_click` and `take_scale_settings_request` route clicks to the host; the price-tag add cell opens the existing context menu at the displayed price, including in Magnet mode. Current close tags include a countdown when a supplied quote belongs to that bar, and volume has a separate tag at the pane bottom.
- `CrosshairStyle::Demonstration` and `CursorType::Demonstration` draw a fading pointer trail that expires while stationary. `TooltipOptions::on_long_press` restricts values to a held pointer, waiting half a second for touch; the floating panel shows OHLC, absolute and percentage change from the previous close, and volume, with one snapped guide and hollow series points. `Chart::set_tooltip_enabled` connects the values switch. Migration: exhaustive cursor matches need a Demonstration arm; tooltip struct literals need `on_long_press` or `..Default::default()`.
- The demo exposes the hovered Data Window in the right rail, quick search, a Trade intent notice and Publish through the existing export dialog. `show_data_window` is exported for hosts that display it independently of the object tree.
- `icons::COMPARE_ADD` and `icons::LAYOUT_SINGLE` provide original comparison and single-pane layout glyphs.
- `chart::render_event_band` draws host-supplied `Marker`s as 22 px badges above a supplied time-axis baseline, aligned to the first bar at or after each event time. It uses the event's text, colour, tooltip and ID, and returns the clicked ID to the host. Events outside the supplied data or plot are left out; existing bar annotations keep their appearance.
- `chart::render_quote_tags` paints independent current close, host-supplied `model::quote::SessionQuote` and abbreviated volume readouts, separating colliding tags and returning each rectangle for input and tick occlusion. `chart::price_axis_width` measures ticks and supplied formatted tag labels. Row spacing follows the host font, and off-scale prices do not hide the other quote values. Short panes keep the close before the session and volume rows. Hosts composing their own axes can route `chart::crosshair_price_action` to an add-at-price menu and `chart::axis_settings_button` to scale settings; the two controls require `icons` and return clicks to the host.
- `widget::Legend` composes an in-pane instrument title, host badge and status marks, current outlined sell/buy quotes with spread, and collapsible volume and visible overlay study rows. Its bar and previous close are supplied independently of current quotes; quote clicks return `QuoteSide` for the host to handle.
- `TextSizes` has separate `chart_title`, `toolbar`, `ohlc`, `axis`, `price_tag` and `bottom_bar` roles, defaulting to 16, 14, 13, 12, 12 and 14 points, with matching constants in `styles::typography`. `scaled` scales them with the general size scale; missing serialised fields use their defaults. Migration: add the roles to `TextSizes` struct literals or use `..Default::default()`. Component call sites choose the roles independently.
- `WidgetBar::widgets` accepts host widget icons, names, ids and top or bottom grouping. Clicks return `WidgetBarAction::WidgetClicked(id)` and switch the active entry independently of the built-in panels. The bar scrolls when its entries do not fit. Migration: an exhaustive match on `WidgetBarAction` needs a `WidgetClicked` arm.
- `Chart::set_price_lines(series, lines)` draws horizontal lines at prices on a series, such as an entry, a stop or a target. A `model::PriceLine` has a price, a colour, a width, a line style, an optional title and a price axis label that can be turned off. The lines follow the series' price scale in every mode, are hidden while their price is off the scale or not finite, and label the axis in the scale's units. Only `SeriesId::MAIN` has price lines; another id is ignored with a warning. `model::LineStyle` is the line style of drawings and price lines; `drawings::LineStyle` remains a re-export of the same type.
- `Chart::scroll_to_time` scrolls the bar nearest a time to the centre of the chart without changing the zoom. A time outside the data shows the nearest end, and with a feed, an older time loads history until it is reached. The demo's go-to-date dialog uses it.
- The chart draws navigation buttons in a row at the bottom of the main pane: zoom out, zoom in, scroll left, scroll right, reset, and auto-scale, logarithmic and percent toggles that show the price scale's current state. Zoom moves by `KeyboardOptions::zoom_step` around the right edge, scrolling by the visible bar count. `ChartConfig::navigation_buttons` (`NavigationButtons::Always`, `OnHover` or `Never`, `Never` by default) sets when they show, and the chart settings dialog's Navigation row edits it. Migration: `ChartConfig` struct literals must set `navigation_buttons` or use `..ChartConfig::default()`.
- `IndicatorDialog::open_tab` opens the indicator dialog on a given tab; `open` opens it on the Indicators tab.
- `IndicatorDialogConfig` implements `Debug` and `Clone`.
- `ui_kit::modal::Modal::height` fixes a modal's outer height for content that fills it, such as a list in a scroll area. The modal keeps 24 px free above and below it in the window and follows the window when it shrinks; `min_height` sets only a floor, so filling content keeps a modal at its largest size.

The message is in the normal text colour at the body size; only the description is muted.
- `icons::DUPLICATE`, two overlapping squares, which the floating selection toolbar's Duplicate button shows.
- `tokens::SizingTokens::control_height`, the minimum height of egui's built-in controls, 18 in `DESIGN_TOKENS`; `apply_to_egui` applies it.
- `Theme::high_contrast()` is a distinct preset: black surfaces, white text, every text colour except disabled text at 7:1 or better on panels and windows, control outlines at 4.5:1, and a light blue accent with black text. It was a copy of the dark theme.
- `Theme::with_accent` sets the accent and derives its hover and pressed shades, the black or white text on it, and the selection colours. `theme::presets()` lists the three presets by name.
- `Theme::text`, `Theme::spacing` and `Theme::radius` hold the type, spacing and corner radius scales; `apply_to_egui` takes the window and menu margins, item spacing and window and menu corner radii from them. `TextSizes::scaled` multiplies the type scale.
- The `serde` feature derives `Serialize` and `Deserialize` for `Theme`; fields missing from the input take the dark theme's values.
- `data::Datafeed`, a callback contract for market data: a feed answers instrument and history requests once through a `data::Reply` (dropping it unanswered reports `FeedError::Unanswered`) and pushes live bars, trades, status and errors through a per-subscription `data::Sink`, from any thread, runtime or browser task. The sink rejects a bar or trade whose slot opens more than one slot and more than a minute after the feed's current time (two weeks for bars of a day or longer), the time being reported through `Sink::set_server_time` or else taken from the system clock. Pushes coalesce on arrival into one bar per time slot, so memory follows the bars that changed rather than the update rate. Supporting types: `HistoryRequest`, `HistoryPage`, `Subscription`, `SubscriptionId`, `FeedStatus`, `FeedError`, `FeedState` and `MaybeSend` in `data`, `Instrument` and `BarClock` in `model`. `FeedError`'s messages name no source, since the host services answer with it too: `NotSupported` reads "not supported" and `Unanswered` reads "no answer". A bar of a day or longer is identified by its UTC day, week from Monday or calendar month, so a feed stamps it inside that period, for example at 00:00 UTC on its trading date, rather than at a session open on the evening before.
- `model::Bar` implements `PartialEq`.
- `data::resample` builds bars of a coarser interval from bars of a finer one, aligned to `BarClock`, so a feed that serves one base interval can back intervals such as 7 minutes or 2 hours. It returns `None` when the finer bars do not nest in the coarser ones, as 5-minute bars do not in 7-minute bars, or when the bars of one slot do not combine into a valid bar, as when their volumes add up to infinity.
- `theme::ThemeExt::active_theme`, for `egui::Context` and `egui::Ui`, returns the theme last passed to `apply_to_egui`, or the dark theme if none was, so components resolve colours while painting.
- `tokens::UiSemanticTokens` gains `panel_bg_floating_dark`, the fill of popups, menus and windows in dark themes. Struct literals of `UiSemanticTokens` must set it.
- A theme toggle in the top toolbar emits `TopToolbarAction::ThemeToggle`.
- `Indicator::update(data, from)` brings a study up to date after the bars from `from` onward changed or were appended, with exactly the values `calculate` gives on the same bars, and `Indicator::is_incremental` reports whether a last-bar update or an append costs time independent of the series length (an earlier change still recomputes in full). `IndicatorRegistry::update_all` updates every study. Both methods have default implementations (a full `calculate`, and `false`), so existing implementors still compile. `SMA`, `EMA`, `BollingerBands`, `RSI`, `MACD`, `Stochastic`, `ATR`, `VolumeWeightedAvgPrice`, `OnBalanceVolume` and `SuperTrend` update incrementally.
- Icons `CHECK`, `MINUS`, `CHEVRON_UP`, `CHEVRON_LEFT`, `CHEVRON_RIGHT`, `STAR_FILLED`, `CODE`, `USERS`, `CROWN`, `DATABASE`, `PENCIL` and `TEMPLATE` in `icons::icons`.
- `ListItemContent::interactive` lets content take its row out of pointer interaction. It defaults to `true`; a disabled `ButtonContent` returns `false`, so its row is neither highlighted nor clickable.
- `data::Sink::push_tick` also keeps each trade, with its price, size, aggressor side and time, in a bounded store for order flow, and `Datafeed::trades` pages historical trades (`TradeRequest`, `TradePage`) so order flow can be rebuilt after a reload. The default answers `FeedError::NotSupported`. History and live trades join exactly when both carry the new `Tick::id` (an exchange trade id or sequence number that never repeats for the symbol), and a live trade whose id the subscription already took is dropped and counted in `FeedState::repeated_ticks`, so a feed may replay its last trades after a reconnect; without ids, trades at the boundary instant may be dropped but are never counted twice.
- Order book depth on the `Datafeed` contract: `Sink::push_depth_snapshot` and `Sink::push_depth_delta` carry a sequence number; a gap, a delta before any snapshot or an invalid update clears the book until the feed pushes a new snapshot, which is asked for once through `Datafeed::request_depth_snapshot`. A delta numbered at or below the last one applied is ignored, whatever it holds. Deltas pushed while the book waits are held, up to 10,000 levels, and the snapshot applies those numbered above it, so a snapshot fetched while the stream runs heals the book. A level with size 0 is removed, and a book is limited to 10,000 levels per side. Rejected updates are counted in `FeedState::rejected_depth`.
- `model::Instrument` describes the full name (`description`), exchange, instrument type, tick size, price decimals, currency, exchange time zone (`model::TimezoneId`) and trading hours (`model::Session`, `model::SessionWindow`), each unknown by default and set with a `with_` method.
- `model::Tick` implements `PartialEq`.
- `DialogFooter::danger` fills the primary action with the danger colour.
- `scales::TimezoneMode`, the time axis timezone mode, now lives next to the time formatters that use it. `config::TimezoneMode` remains as a re-export of the same type.
- `ChartState::revision` identifies the bars before the last one: it changes when one of them is corrected or bars are removed, and stays the same when bars are appended or the last bar updates.
- Per-drawing settings: `Drawing::volume_profile` (`drawings::VolumeProfileConfig`, 1 to 1,000 price rows and the value area's share of the volume, 24 rows and 70% by default), `Drawing::regression_trend` (`drawings::RegressionTrendConfig`, the band distance in standard deviations, above 0 and up to 10, 2 by default) and `Drawing::position_size` (`drawings::PositionSize`, a fixed quantity, or the quantity that loses a given amount or a percentage of an account size at the stop). `None` uses the defaults. The constructors of the two configs reject values out of bounds; a position size out of bounds reads as n/a.
- `Drawing`, `DrawingToolType`, `LineStyle`, `ArrowStyle`, `FontWeight`, `TimeframeVisibility`, `FibonacciLevel`, `FibonacciConfig`, `VolumeProfileConfig`, `RegressionTrendConfig` and `PositionSize` implement serde `Serialize` and `Deserialize`. A tool type is written as its variant name; a `Drawing` leaves out its id, points and completion state; the volume profile and regression trend settings are checked against their bounds on load; the per-timeframe visibility set is written sorted, so saving the same drawings gives the same file.
- `services::Storage`, a callback contract through which the host keeps named JSON documents for the library: it lists, loads, saves and deletes the documents of a `services::StoreKind` (`Settings` or `Drawings`) and answers through a `data::Reply`, from any thread, runtime or browser task. Nothing calls it yet. ([#198](https://github.com/userFRM/egui-charts/issues/198))
- `services::SymbolSearch`, a service the host implements to answer symbol searches from any source of instruments, separately from the feed: it takes a `services::SymbolQuery` (the typed text, optional instrument type and exchange filters, and a result limit) and answers with `Instrument`s through a `data::Reply`. `Vec<Instrument>` implements it: it matches the text against symbol and description ignoring case, applies the filters, and lists an exact symbol first, then symbols that start with the text. Nothing calls the service yet. ([#380](https://github.com/userFRM/egui-charts/issues/380))
- `services::Broker`, a callback contract for one trading account at the host's broker, real or simulated: it places and cancels orders, answering through a `data::Reply`, and pushes the account, orders, positions, executions and connection status as `services::AccountEvent`s into an `Events` stream. The trading model is in `model`: `OrderType`, `OrderRequest`, `Order`, `OrderStatus`, `Position` (signed net quantity), `Execution`, `Account` and `Capabilities` (the order types the account accepts). The library holds no balances or positions. Nothing calls the service yet. ([#216](https://github.com/userFRM/egui-charts/issues/216))
- `services::Signals`, through which a host supplies markers, levels and zones from its own analytics (`model::Signal`, `SignalShape`, `SignalId`, `Direction`) as `services::SignalEvent`s, pushed from any thread into a `services::Events` stream that holds at most 10,000 pushes between frames and ends when it lags or the chart stops listening ([#381](https://github.com/userFRM/egui-charts/issues/381)).
- `model::StrategyReport` describes a strategy run from any source: its trades, each with the net profit the host computed, its equity curve and the settings to show. `StrategyReport::performance` computes the metrics with one definition each: net, gross and average profit, profit factor, win rate, maximum drawdown in money and as a fraction of the peak, and the Sharpe and Sortino ratios, annualised by the steps per year the equity curve covers and unavailable for a curve spanning less than 13 weeks. An undefined metric is `None`, invalid trades and equity points are skipped and counted, a non-finite number is saved as `null` in JSON and loads back as NaN, so a report with one loads with the same metrics, and `StrategyReport::trades_csv` exports the valid trades. Supporting types: `StrategyTrade`, `StrategyExit`, `StrategySide` and `StrategyPerformance`.
- `services::Alerts`, through which the host keeps and evaluates price alerts: it pushes its alerts, their changes and their triggers as `services::AlertEvent`s into a `services::Events` stream, including triggers that fired while the application was closed, and saves or removes the alerts the user edits, answering through a `data::Reply`. The alert model (`model::Alert`, `AlertId`, `AlertCondition`, `AlertFrequency`, `AlertStatus`) is serialisable so a server can store and evaluate the same type. Nothing calls the service yet. ([#211](https://github.com/userFRM/egui-charts/issues/211))
- The Negative and Positive Volume Index plot their signal line, the 255-bar EMA of the index seeded with its first value, so it starts at bar 0 like the index. The index is unchanged. Migration: `NegativeVolumeIndex` and `PositiveVolumeIndex` output `IndicatorValue::Multiple(vec![index, signal])` instead of `Single(index)`, and report two lines and two colours; code that matched `Single` reads the index as the first value.
- `config::KeyboardAction::shortcuts` returns the key combinations for an action, as `egui::KeyboardShortcut`s, and `KeyboardAction::shortcut` the first of them, which the context menus show.
- `AlertKind::color` and `ToastKind::color` return the theme's status colour for an alert or toast kind.
- `MessageKind::Warning`: `status_message` draws it in the theme's warning colour. Migration: a `match` on `MessageKind` needs a `Warning` arm.
- `TopToolbarState::can_undo` and `can_redo` disable the top toolbar's undo and redo buttons, whose tooltips then read "Nothing to undo" and "Nothing to redo"; both default to `true`. Migration: struct literals of `TopToolbarState` set both fields or use `..Default::default()`.
- `Chart::set_data(series, bars)` replaces the bars, for history or a replay window, and `Chart::update(series, bar)` merges one bar by the rules a feed's `Sink::push_bar` follows, matched by open time, or by the slot of the timeframe for a chart built with a feed: a bar that matches a stored bar replaces it, a newer one is appended and an older one is inserted in order. `Chart::bars(series)` reads the bars, and `Chart::feed_state(SeriesId::MAIN).rejected_bars` counts the bars dropped as invalid. Only `SeriesId::MAIN` holds bars; a call with another id is ignored with a warning. `SeriesId` is re-exported from `widget`.

## [0.2.0] - 2026-06-04

### Added

- Click-to-select for indicators and series on a single unified selection model, with on-chart selection handles.
- Right-click context menus for the chart background, a series, and a drawing, opened directly from the chart.
- Hover tooltip with an OHLC readout, in floating, tracking, and magnifier modes.
- Session-break dividers and optional background shading, with a `ChartBuilder::with_session_breaks` toggle (timeframe-aware day, week, and month boundaries).
- TPO / Market Profile chart type with point-of-control and a contiguous 70% value-area computation, rendered as letters or blocks.
- Remove an indicator from its pane legend; `Chart::take_indicator_remove` surfaces the request to host applications.
- Host interaction plumbing: `Chart::take_right_click` and `RightClickTarget`, `TradingChart::take_context_action` and `ChartContextAction`.
- `TradingChart` controller helpers: `config_mut`, `apply_series_settings`, `remove_indicator`, `set_indicator_visible`, and `remove_drawing`.
- The bundled demo is now a complete application: every toolbar action, all dialogs, the object-tree and alerts panels, and bar replay are wired, and it is published as a live WebAssembly build.

### Fixed

- Backtest equity now signs short positions correctly, and the Sharpe, Sortino, and Calmar ratios are no longer inflated by a percent-versus-fraction unit mismatch.
- RSI output length now matches the bar count and is no longer misaligned by one bar.
- The indicator factory constructs every built-in indicator by name rather than a small subset.
- Heikin-Ashi candles are computed over the full series, so they no longer change shape on pan and zoom.
- Coordinate and formatter transforms guard against flat price ranges and zero denominators.
- Drawing hit-testing is unified through a single path, and an undone add now survives history pruning so redo still works.
- Selection handles render correctly when the chart is scrolled.
- Embedded SVG icons render because the image loaders are now installed automatically, and notification timing no longer panics on WebAssembly.
- The bundled examples compile again.
- Issue #1: the focus ring appeared when the pointer merely hovered the chart. Issue #2: the examples did not compile.

### Changed

- Renamed `ui::stubs` to `ui::model`.
- Corrected the documented metrics to match the code.
- CI now builds the examples and runs the documentation and feature-gated tests.

### Removed

- The unused `egui_plot` dependency.
- Superseded legacy renderers and the unused render pipeline.

Thanks to @intelligentnet and @sstscrypto for the reports that became issues #2 and #1.
